# Specifications

This folder holds the specifications for the open formats. Each is a written contract with a version, and each format change updates its specification, its JSON Schema and its version field in the same pull request (rule 24 of `AGENTS.md`).

**Status: empty.** The specifications arrive in their own cards: the rule-pack format (P0-03), the results format (P0-04), configuration, exceptions and baseline files (P0-05), the licence token (P0-06), the evidence-sink transport (P0-07) and the middleware API contract (P3-01).
