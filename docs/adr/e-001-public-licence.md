# E-001: Apache-2.0 for the public repository

## Context

The free engine, command-line interface, middleware and formats need clear terms
for reuse and contribution.

## Decision

Use [Apache-2.0](../../LICENSE), as stated in the [README](../../README.md#licence).
This records the existing licence; it does not change its terms.

## Status

**Accepted — recorded on 13 November 2026.** The existing [LICENSE](../../LICENSE)
and [README](../../README.md#licence) already establish Apache-2.0. The owner
confirmed that implemented decisions and decisions accepted elsewhere are approved.
The D-006 source reference is retained; whether it satisfies issue #1's R-number
criterion is a traceability question, not pending licence approval.

## Consequences

Downstream users can find the terms in LICENSE. Dependency licence checks still
apply. This record grants no new legal approval or dependency permission.

## Alternatives considered

A different licence would change the established terms and require a separate
owner decision. No replacement licence is proposed here.
